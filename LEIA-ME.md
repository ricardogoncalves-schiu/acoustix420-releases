# AcoustiX420 para Android

A app do sonómetro CESVA SC420 (SCHIU, engenharia acústica). Aqui está só a última versão para instalar; a app
atualiza-se sozinha a partir daqui (pergunta ao abrir, quando há uma versão nova).
- Versão: **1.7.10**
- Ficheiro: `AcoustiX420.apk` (47.1 MB)
- SHA-256: `48f4bdc4e30ef21446090a3f0280c89a903434811e61ae9c300d89b039d4f641`

Versão de teste: 1.7.12 (pasta `teste/`; só para os telemóveis de teste).

Para instalar pela primeira vez: descarregar o `AcoustiX420.apk` no telemóvel, abrir e autorizar a instalação.
